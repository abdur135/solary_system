Tentang Website

Tujuan dan manfaat belajar tata surya

Tujuan Website

Website ini dibuat sebagai media pembelajaran interaktif untuk memahami sistem tata surya. Dirancang khusus untuk mahasiswa dan pelajar yang ingin mempelajari planet-planet, karakteristiknya, serta fenomena luar angkasa secara visual dan menarik.

Dengan pendekatan multimedia yang menggabungkan teks, gambar, video, dan animasi, diharapkan pengguna dapat lebih mudah memahami materi tata surya.

Manfaat Belajar

Mempelajari tata surya memberikan banyak manfaat, antara lain:

  • Memahami posisi Bumi di alam semesta
  • Mengetahui karakteristik unik setiap planet
  • Meningkatkan rasa ingin tahu tentang sains dan astronomi
  • Mengembangkan pemikiran kritis melalui fenomena alam
  • Menumbuhkan kesadaran akan pentingnya menjaga Bumi

Materi Pembelajaran

Website ini mencakup materi lengkap tentang 8 planet dalam tata surya: Merkurius, Venus, Bumi, Mars, Jupiter, Saturnus, Uranus, dan Neptunus. Setiap planet dilengkapi dengan data diameter, jarak dari Matahari, lama revolusi dan rotasi, serta deskripsi singkat.

Teknologi yang Digunakan

Website ini dibangun menggunakan teknologi web modern:

  • HTML5 untuk struktur halaman
  • CSS3 untuk tampilan dan animasi
  • JavaScript untuk interaktivitas
  • Bootstrap 5 untuk layout responsif
  • AOS Animation untuk efek scroll
  • Font Awesome untuk ikon
